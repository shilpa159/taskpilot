Process

From one line to a working board

Five steps, start to finish — the same order every time.

01

Register & sign in

Create an account with an email and password. No verification steps in the way.

02

Create a project

Give it a name. Projects keep separate goals from bleeding into one board.

03

Type a goal

Write what you're trying to achieve, in plain language — one line is enough.

04

AI breaks it down

Claude reads the goal and returns ordered subtasks, each with a time estimate.

05

Edit, assign, track

Drag cards across To do, In Progress, and Done. Rewrite, reassign, or delete anything.

What's in the box

Built for planning, not just listing tasks

AI TASK BREAKDOWN

One goal in, a sequenced plan out

The Anthropic Claude API reads a one-line goal and returns an ordered list of subtasks with time estimates — planning starts already organized, not blank.

KANBAN BOARD

Drag tasks across three states

To do, In Progress, and Done. Reordering and status changes update instantly, no page reloads or lost position.

PROJECTS

Group tasks, not just tag them

Every task lives inside a project. Switch between projects from the sidebar and keep unrelated goals from mixing.

AUTH & ISOLATION

Secure by default

JWT-based sessions and hashed passwords. Every account only ever sees its own projects and tasks.
